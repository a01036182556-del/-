# 금도건설 Claude 활용분석 — 판단 전용(v1.3, 수집·전송은 사용자 bat)

★ **역할 분리(핵심)**: 이 스킬(Claude)은 **판단만** 한다. **원본 로그를 직접 스캔하거나 외부 서버로 직접 전송하지 않는다.** 수집·전송은 사용자가 바탕화면 `활용분석_제출도구\1_수집.bat`·`2_전송.bat` 을 더블클릭해 실행한다. (그래야 보안에 민감한 PC에서도 누구나 동일하게 동작한다 — 이건 우회가 아니라 *구조적 분리*다.)

## ⛔ 절대 원칙 (개인정보)
1. 대화 **원문**·파일 **내용**·비밀번호·토큰·키는 **보지도 전송하지도 않는다.** gd_signals(통계요약)만 읽는다.
2. 서버로 가는 `활용사례`·`소스설명`·**PDF 본문**에 거래처/고객사명·회장/임원 실명·금액·은행/대출·부채비율·세무·급여·법적사안(부당해고·단협)을 **절대 쓰지 말 것** → 업무 *성격*만 일반화.
3. 저장 전 **자가검수(필수)**: 위 금지정보가 한 글자도 없는지 확인.

## 절차

### Step 0 — 준비 확인
- 사용자가 **`1_수집.bat` 을 더블클릭**했는지 확인. 안 했으면 → "바탕화면 **활용분석_제출도구 → 1_수집.bat** 을 먼저 더블클릭하고 '됐어' 라고 알려주세요" 안내 후 대기. (Claude가 직접 -Scan 을 실행하지 말 것.)
- 작업폴더(WorkDir) = `$env:TEMP\gd_usage_run` (bat 과 공유). **PDF 서식**은 플러그인의 `report_template.html`:
  ```
  (Get-ChildItem "$env:USERPROFILE\.claude\plugins" -Recurse -Filter report_template.html -ErrorAction SilentlyContinue | Select-Object -First 1).FullName
  ```

### Step 1 — 신호 읽기 + 신선도 게이트(필수)
`$env:TEMP\gd_usage_run\gd_signals.json` 을 읽는다. **판단 전 게이트:**
- `메타.버전` 이 현재(1.3.x) 가 아니거나, `메타.스캔시각` 이 방금 것이 아니면 → **판단 말고 "1_수집.bat 을 (다시) 돌려주세요" 요청** 후 대기(옛/미실행 스캔으로 판단·PDF 금지).
- ★**저사용 진단(중요·누락 방지)**: `통계.활성일수 ≤ 1` 그리고 `통계.총도구호출 ≤ 60` 이면(=이 PC 로컬 기록이 거의 없음) → 점수·PDF 내기 전에 **반드시 사용자에게 확인**: "이 PC에서 잡힌 Claude(Code/코워크) 기록이 하루치뿐입니다. ① 주로 **claude.ai 웹/앱(일반챗)** 으로 쓰시나요?(웹 사용은 로컬에 안 남아 회사가 집계 불가) ② 혹은 **다른 PC**에서 주로 쓰시나요? ③ 이 PC에서 Code/코워크를 많이 쓰셨는데 이 수치라면 `메타.탐색경로`(1_수집.bat 콘솔의 '탐색된 데이터 경로')를 캡처해 경영지원실로 보내주세요(수집 위치 점검)." → 답을 듣고 진행하되 **저사용 사실을 숨기지 말 것.**
- `소스별.코워크 == 0` 이면 코워크/에이전트를 거의 안 쓰신 것(코드 위주)으로 명시하고 진행.
- ★**객관 80점은 `gd_signals.객관점수`·`객관분해`(활동량·지속성·최근성·다양성·몰입)에 이미 계산돼 있다.** Claude는 이 값을 **그대로** PDF·설명에 쓴다(객관 점수를 새로 만들거나 바꾸지 말 것).

### Step 2 — 성명 확인
`~/.claude/.usage_name` 있으면 사용. 없으면 **성명** 1회 질문 후 캐시 저장. (부서·회사는 서버가 명단으로 확정.)

### Step 3 — AI 판단 → `gd_usage_submit.json`
★ **Claude가 정하는 건 AI 20점과 분류·서술뿐**(객관 80점에 영향 0). 판단 전:
1. **확인 질문 1회**: "반영할 **주요 업무 시스템·전사 프로그램**(그룹웨어·ERP 등 *Claude 밖* 프로그램은 사용기록에 안 잡힘)과 **직접 만든/자주 쓰는 스킬**이 있으면 알려주세요. 없으면 '없음'." → 답은 **활용분야·활용사례에만** 반영. ★**AI 확산/정착/자동화 축은 실제 Claude 사용 근거(스킬사용·코드/코워크량·커넥터·skill-creator)가 있을 때만** 올린다 — *Claude로 만들지 않은 외부 시스템 운영을 말만으로 AI 만점 내지 말 것.*
2. **스킬 = 강점**: `스킬사용`/`스킬종수`>0 또는 `skill-creator` 호출이 보이면 '지식 자산화(스킬화)'를 **강점**으로(개선점 금지). 회사 스킬(`geumdo`·`gd-`·`villa`·`chairman` 접두)은 정착·자동화 근거.
3. 활용분야는 `스킬사용·커넥터·도구분포`를 근거로(추측 최소화).

**SAFE 필드만** `$env:TEMP\gd_usage_run\gd_usage_submit.json` 저장:
- `성명`(필수)·`부서`(있으면)·`회사`·`추출일시`
- `활용분야`: [계약관리·인사/HR·법령/규정분석·회계/정산·엑셀/데이터자동화·공문/문서작성·PPT/발표자료·PDF처리·스킬/프로그램·디자인/시각화] 중 해당(배열)
- `산출물유형`: {"엑셀/데이터":N,"문서작성":N,"한글문서(HWP)":N,"PPT/발표":N,"PDF/문서":N} (표시용)
- `AI축`: {문제정의,자동화,복잡도,정착도,확산} 각 1~5 (정직하게)
- `활용사례`: 마스킹된 짧은 문장 1~3개 배열(원칙2)
- `소스설명`: {"코워크":"…","코드":"…","일반챗":""}
- `공유`: 전사 모범사례면 `true`
→ 저장 전 **자가검수**(금지정보 0건) 통과.

### Step 4 — 본인 PDF 리포트
`report_template.html` 복사 → `[[...]]` 만 채워 **A4 PDF** `Claude활용분석_<성명>.pdf` 를 `$env:TEMP\gd_usage_run` 에 저장. **점수분해(활동량·지속성·최근성·다양성·몰입)는 `gd_signals.객관분해` 값을 그대로**, AI 는 Step 3 판단값을 쓴다(이러면 PDF=대시보드 점수 동일). **CSS·구조 변경 금지.** HTML→PDF 변환은 로컬(예: Edge `--headless --print-to-pdf`)로 — 이는 외부 전송이 아니므로 안전.

### Step 5 — 전송 안내 (★Claude는 실행하지 않음)
사용자에게: **"바탕화면 활용분석_제출도구 → `2_전송.bat` 을 더블클릭하세요. 화면에 [점수]… 와 [OK] 데이터 전송 이 뜨면 완료입니다."** Claude가 직접 -Submit 을 실행하려 하지 말 것(보안 차단 대상 + 구조상 사용자 몫).

### Step 6 — 마무리
사용자가 콘솔 결과(점수·레벨)를 알려주면 확인하고 **세 줄**: ① 종합점수·레벨 ② 객관 분해(활동량·지속성·최근성·다양성·몰입)+코드/코워크 실측 ③ "대시보드 `https://usage.gd-business.co.kr`" 안내.

## 참고
- **객관 80 = 스크립트 실측·곡선**(활동량 log·지속성 √활성일·최근성·다양성·몰입). 한 세션으로 만점 안 되며 사용량 차이만큼 점수가 벌어진다. **AI 20 = Claude 판단(근거 기반).** 코호트가 모이면 서버가 '상위 %' 백분위로 자동 보정.
- 같은 사람 재제출 = 최신 1건 갱신(중복 없음). 토큰·서버주소는 엔진(제출도구의 ps1)에 내장 — 안전. 명단 외 성명은 서버가 거절.
